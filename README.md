
# Praktikum 4 - CSS Layout

## Tujuan
Memahami Box Element, CSS Float, Clearfix, HTML Semantic Element, dan pembuatan layout website sederhana.

## 1. Box Element
Membuat tiga kotak menggunakan HTML dan CSS dengan warna merah, kuning, dan hijau. Menambahkan Div 4 untuk mempraktikkan properti clear.

## 2. Layout Sederhana
Membuat kerangka website menggunakan header, navigasi, hero panel, main content, sidebar, dan footer.

## 3. Navigasi dan Hero Panel
Mengatur menu navigasi dan membuat panel pembuka bertuliskan Hello World.

## 4. Main Content dan Sidebar
Menambahkan tiga kotak konten, widget sidebar, dan footer.

## 5. Artikel
Menambahkan dua artikel dengan gambar yang berada di sisi kiri dan kanan.

## 6. Halaman About
Membuat halaman deskripsi diri dan portofolio sederhana.

## 7. Halaman Contact
Membuat formulir berisi nama, email, dan pesan.

## Kesimpulan
Praktikum ini membantu memahami penggunaan HTML dan CSS untuk menyusun layout website, mengatur posisi elemen, dan membuat halaman web sederhana.
